`Stdb.project(Module)` is the Effect-native SDK companion for a module.

```typescript
import * as Effect from "effect/Effect"
import * as Stdb from "effect-spacetimedb"

declare const uri: string
declare const databaseName: string
declare const token: string

const Users = Stdb.Group.make("Users").add(
  Stdb.Fn.reducer("userUpsert", {
    params: Stdb.struct({ userId: Stdb.string(), name: Stdb.string() }),
  }),
)

const Module = Stdb.Module.make("app").add(Users)
const Example = Stdb.project(Module)
const HttpLive = Example.client.http.layer({
  uri,
  databaseName,
  token,
  callDurationMax: "10 seconds",
})

const program = Effect.gen(function* () {
  const client = yield* Example.client.http.Tag
  yield* client.groups.Users.reducers.userUpsert({ userId: "u1", name: "Ada" })
}).pipe(Effect.provide(HttpLive))
```

The projection contains:

- `client.http`: typed Effect service, direct `make`, and layer constructors.
- `client.ws`: scoped/layered WebSocket sessions over generated native bindings.
- `targets`: public persistent-table, event-table, and all-public-table targets.
- `module`, `tables`, `reducers`, `procedures`, `httpHandlers`, and `lifecycle`
  metadata for tooling.
- `Stdb.toHttpApi(Module)`: an Effect `HttpApi` projection for typed HTTP
  routes.

effect-spacetimedb's client surface uses Effect services and
typed errors. It does not replace the native generated WebSocket cache; it wraps
it with scoped resources, projected callables, and subscription helpers.

Every key in the projection — table, event-table, and view keys passed to
`subscribe`, `streamTable`, `targets`, and the session's `db` — is the
**contract key** you declared, which is also the camelCase accessor key
`spacetime generate` emits. The wire name appears only inside SQL and
subscription text. See [Codegen](/core-concepts/clients/codegen).

## Calls to mounted modules

Use the mount accessor at each level of the WebSocket or HTTP client. For example, `session.procedures.stockRoom.saveItem(args)` and `http.procedures.stockRoom.saveItem(args)` call the same library procedure. Reducers nest the same way. Subscribed rows appear under `session.cache.tables.stockRoom` or `session.cache.views.stockRoom`. HTTP routes belong to the root. Only Effect module mounts contribute typed members. See [Submodules](/core-concepts/databases/submodules).

## Group-Scoped HTTP Clients

The HTTP client keeps its flat `reducers`, `procedures`, and `httpHandlers`
records and also projects every authored group as a namespace:

```typescript
import * as Stdb from "effect-spacetimedb"

declare const uri: string
declare const databaseName: string
declare const token: string

const Users = Stdb.Group.make("Users").add(
  Stdb.Fn.reducer("userUpsert", {
    params: Stdb.struct({ userId: Stdb.string(), name: Stdb.string() }),
  }),
  Stdb.Fn.procedure("userGet", {
    params: Stdb.struct({ userId: Stdb.string() }),
    returns: Stdb.option(Stdb.struct({ userId: Stdb.string(), name: Stdb.string() })),
  }),
)
const Module = Stdb.Module.make("app").add(Users)
const Example = Stdb.project(Module)
const client = Example.client.http.make({
  uri,
  databaseName,
  token,
  callDurationMax: "10 seconds",
})
const users = Example.client.http.group("Users", {
  uri,
  databaseName,
  token,
  callDurationMax: "10 seconds",
})

const write = client.groups.Users.reducers.userUpsert({ userId: "u1", name: "Ada" })
const read = client.groups.Users.procedures.userGet({ userId: "u1" })
const scopedWrite = users.reducers.userUpsert({ userId: "u1", name: "Ada" })
```

For a narrower type at a consumer boundary, construct only one group view:
`Example.client.http.group("Users", { uri, databaseName, token, callDurationMax })`. The result
contains only that group's `reducers`, `procedures`, and `httpHandlers`.

HTTP clients and WebSocket sessions both expose groups under `groups`.
A group is built on first access. Its reducer and procedure functions,
including `.raw`, have the same identity as the corresponding flat calls.
HTTP groups also include their HTTP handlers. Group ids must be JavaScript
identifiers. Prototype names such as `constructor` are reserved.
`session.groups.identity` and `session.identity` are independent members.

## Raw Calls And Failures

Reducer and procedure functions expose a typed call and a `.raw` variant. The
typed call decodes declared domain errors into the error channel directly. The
raw variant preserves a `DomainCallError` wrapper so callers can distinguish a
remote declared error from transport, rejection, or decode failures.

```typescript
import * as Effect from "effect/Effect"
import * as Stdb from "effect-spacetimedb"
import * as StdbClient from "effect-spacetimedb/client"

const AppErrors = Stdb.errors.namespace("App")({
  UserMissing: Stdb.error({ userId: Stdb.string() }, { status: 404 }),
})

const Users = Stdb.Group.make("Users").add(
  Stdb.Fn.procedure("userGet", {
    params: Stdb.struct({ userId: Stdb.string() }),
    returns: Stdb.option(Stdb.struct({ userId: Stdb.string(), name: Stdb.string() })),
    errors: AppErrors,
  }),
)

const Module = Stdb.Module.make("app").add(Users)
const Example = Stdb.project(Module)

const program = Effect.gen(function* () {
  const client = yield* Example.client.http.Tag
  return yield* client.procedures.userGet.raw({ userId: "u1" })
}).pipe(
  Effect.catchTag("DomainCallError", (failure: StdbClient.DomainCallError<unknown>) =>
    Effect.fail(failure.error),
  ),
)
```

The exported failure model is:

| Type | Meaning |
| --- | --- |
| `CallFailure<E>` | A typed HTTP call's error union: declared errors, `RemoteRejectedError`, `TransportError`, or `StdbDecodeError`. |
| `RawCallFailure<E>` | A raw HTTP call's error union: `DomainCallError<E>`, `RemoteRejectedError`, `TransportError`, or `StdbDecodeError`. |
| `WsCallFailure<E>` | A typed WebSocket call's error union: `CallFailure<E>` plus `WsConnectionFailure`. |
| `RawWsCallFailure<E>` | A raw WebSocket call's error union: `RawCallFailure<E>` plus `WsConnectionFailure`. |
| `WsConnectionFailure` | What only a WebSocket session can add: `ConnectionLostError`, `CallNotSentError`, or `ConnectionIdentityChangedError`. |
| `DomainCallError<E>` | Declared error preserved as a wrapper by `.raw`. |
| `ConnectionLostError` | The connection was lost before a terminal response arrived (or the session had already ended); the call's outcome is unknown. |
| `WsProtocolError` | A server message failed to decode or apply. The SDK error is available as its cause. |
| `CallNotSentError` | With automatic reconnect: the session was reconnecting, so the call was never sent. Safe to retry once it is live. |
| `ConnectionIdentityChangedError` | With automatic reconnect: a reconnect came back under a different identity and ended the session. |
| `RemoteRejectedError` | The remote side rejected the call without a decodable declared error. |
| `TransportError` | The HTTP or WebSocket transport failed before a typed response arrived. |
| `StdbDecodeError` | A response, row, event, or payload could not be decoded with the module contract. |

An HTTP call has no connection to lose, so its error type names none of the
three connection errors, and a `catchTags` on it needs no arm for them.

## HTTP API Base URL

Use `Stdb.httpApiBaseUrl` with `Stdb.toHttpApi(Module)` when you want a
stock Effect `HttpApiClient` over typed `post`, `put`, or `patch` routes.

```typescript
import * as Effect from "effect/Effect"
import * as HttpClient from "effect/http/HttpClient"
import * as HttpClientRequest from "effect/http/HttpClientRequest"
import * as HttpApiClient from "effect/http-api/HttpApiClient"
import * as Stdb from "effect-spacetimedb"

declare const uri: string
declare const databaseName: string
declare const token: string

const api = Stdb.toHttpApi(Module)

const program = Effect.gen(function* () {
  const client = yield* HttpApiClient.make(api, {
    baseUrl: Stdb.httpApiBaseUrl({ uri, databaseName }),
    transformClient: HttpClient.mapRequest(
      HttpClientRequest.bearerToken(token),
    ),
  })

  return client
})
```
