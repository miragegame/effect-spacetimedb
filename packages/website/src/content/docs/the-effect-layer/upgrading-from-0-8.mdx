## Install the matching tools

Use Node `^22.23.4 || ^24.22.1 || >=26.12.1`, Effect `^4.1.1`, and SpacetimeDB **2.16.1** for the JavaScript SDK, CLI and database host. Even a module that uses default storage emits the new table-cache schema section.

1. Install `effect-spacetimedb@0.9.0` and pin `spacetimedb@2.16.1` in both the module and client projects.
2. Replace the SDK 2.14 patch with the [2.16.1 patch](https://github.com/miragegame/effect-spacetimedb/blob/v0.9.0/patches/spacetimedb@2.16.1.patch). It fixes comparisons of object-valued range keys, unique index classification and branded primitive builder inputs.
3. Configure your package manager to apply the patch and reinstall. For Bun, put the following entry in the root `package.json`. For pnpm, place the same mapping under `pnpm.patchedDependencies` or in `pnpm-workspace.yaml`. Other installers need an equivalent patch step.

```json
{
  "patchedDependencies": {
    "spacetimedb@2.16.1": "patches/spacetimedb@2.16.1.patch"
  }
}
```

## Update contracts and handlers

Import the root with `import * as Stdb from "effect-spacetimedb"`. For example, declare a reducer with `Stdb.Fn.reducer`, add it to `Stdb.Group.make("Users")`, then add the group to `Stdb.Module.make("app")`.

| Previous spelling | Current spelling or replacement |
| --- | --- |
| `StdbFn` | `Fn` |
| `StdbGroup` | `Group` |
| `StdbModule` | `Module` |
| `StdbHttp` | `Http` |
| `StdbHttpGroup` | `HttpGroup` |
| `StdbBuilder` | `Builder` |
| `AnyStdbModule` | `AnyModule` |
| `StdbBuildPlan` | `BuildPlan` |
| `StdbValueType` | `ValueType` |
| `StdbDiagnostic` | `Diagnostic` |
| `StdbDiagnosticSeverity` | `DiagnosticSeverity` |
| `StdbDiagnosticCode` | `DiagnosticCode` |
| `StdbTypeDescriptor` | `TypeDescriptor` |
| `StdbHostFailure` | `HostFailure` |

Remove `public` from reducers, procedures and views. Client-callable functions were already reachable on the host. For a restricted read, use a private table and a procedure that checks the sender. Tables keep their visibility setting. Scheduled, lifecycle and settle functions stay outside the projected client.

Replace a column’s `.name("display_name")` with `.columnName("display_name")`. Use `.named("UserView")` to name a generated struct type. Check existing column names before republishing because correcting a mistaken column name changes the stored schema.

An integer column can use `.autoInc()` with or without a primary key. Remove workarounds that treated chained field options as optional values. A zero on update also requests the next sequence value. Optional columns cannot carry a sequence.

Other removed names and members:

| 0.8 | 0.9 |
| --- | --- |
| `Stdb.enumType(...)` | `Stdb.enum(...)` |
| `Builder.groupChecked(...)` | `Builder.group(...)`, or `groupPrechecked(...)` for a record already annotated `GroupCheckedHandlers` |
| `LifecycleKeys` from `/server` | `LifecycleName` from the root |
| `StdbEventContextType`, `StdbReducerOutcomeType` from `/client` | `StdbEventContext`, `StdbReducerOutcome`, which are types as well as values |
| `WsSubscriptionHandleLike` from `/client` | `SubscriptionHandleLike` |
| `db.table.key.replace(...)` | `db.table.key.update(...)` |
| `db.table.index.deleteAll(...)` | `db.table.index.delete(...)` |
| the handler context's deprecated `identity` | `ctx.databaseIdentity` |
| `WaitUntilOptions.interval` | removed; `waitUntil` is event-driven and never read it |

Use `Stdb.Builder.group` for implementations and `build(module, implementations)` from `effect-spacetimedb/server-compiler` for the module entry. Replace `Server.make`, `ServerInstance`, `MakeOptions` and their single-handler and transaction helpers with module accessors. A `SyncRunner` provides `runSync` and `runSyncExit`. Remove calls to `dispose` and references to `SyncRunnerLike` or `StdbServerDisposedError`. Use `toSyncRunner` to adapt a context.

Change `client.Users.reducers.userUpsert` to `client.groups.Users.reducers.userUpsert`. The same path works on WebSocket sessions, including a session delivered by a supervisor or atom. Each group is created on first access and retains its identity. Its functions and their `.raw` variants are the same objects available under the flat `reducers` and `procedures` records. HTTP groups also have `httpHandlers`. A scoped HTTP client from `project(module).client.http.group("Users", config)` already represents one group. Names such as `cache`, `identity` and `groups` are valid group ids.

Time options accept Effect `Duration.Input`. A number still means milliseconds. Calls and connection acquisition default to 30 seconds. Set `callDurationMax` or `connectDurationMax` to `Duration.infinity` to disable that timer. A WebSocket call that exceeds its deadline ends the connection and fails with `ConnectionLostError`. Its outcome is unknown. Set the deadline above the longest expected operation. The procedure HTTP adapter also accepts a duration as its `timeout`.

The supervisor defaults to an initial delay of 250 milliseconds and a ceiling and stability window of 30 seconds each. A short-lived connection continues the previous backoff. The delay resets after a connection stays live for the stability window. Delays must be finite and nonnegative, and the stability window must be finite and positive.

Use `CallFailure<E>` and `RawCallFailure<E>` for HTTP. On WebSocket calls use `WsCallFailure<E>` or `RawWsCallFailure<E>`. Remove HTTP recovery arms for `ConnectionLostError`, `CallNotSentError` and `ConnectionIdentityChangedError`. If you construct `SubscriptionInvalidatedError` in a test, supply its `kind`. A custom `TableAtomSession` must implement `isRevoked()` and `rowsOwner()`.

## Update server failure handling

Server table reads, streams, index lookups and deletes have error type `never`. A missing `find` result is `undefined`. `findOrFail` fails with the error you supply. Remove `catchTag`, retry and `orDie` around table operations whose error channel is now empty. An unexpected host call or malformed stored row dies with `StdbTableOperationDefect`. Import the class from `effect-spacetimedb/server` and inspect its `table`, `op` and `cause` in a defect observer. Client-side decoding still reports `StdbDecodeError` for malformed data received from the server.

| Table operation | Typed failures |
| --- | --- |
| Insert, bulk insert, schedule | `StdbUniqueAlreadyExistsError` for unique constraints, `StdbAutoIncOverflowError` for sequences and `StdbScheduleDelayTooLongError` for scheduled tables |
| Primary-key update | The applicable write errors above plus `StdbNoSuchRowError` |
| Outbox insert | Applicable insert errors plus `OutboxRowTooLargeError` for the configured byte bound |
| Read, delete, clear | None |

`withTx` and scoped transaction helpers propagate the body's typed errors. The host transaction can also fail. A transaction no longer adds a decode error of its own. Its scope closes before commit and it inherits caller-provided services and log annotations. A finalizer that dies aborts the transaction. Keep external side effects outside a transaction body because the host can retry it.

Update error class imports, string tags and pattern matches together. Local class names change independently of stored rows and declared wire errors.

## Publish the module and regenerate its client

Coordinate the module and client upgrade. **Every client-callable procedure now returns an `ok` or `err` envelope**, including procedures with no declared errors. A raw success is `[0, value]`. A raw failure is `[1, carrier]`. The carrier is a string containing either the declared error payload or a version 1 `UndeclaredFailure` with a reason and message. A 0.8 client cannot decode the new result from a formerly unwrapped procedure.

```sh
spacetime generate --lang typescript --module-path . --out-dir src/module_bindings --yes
```

The typed client decodes undeclared procedure failures as `RemoteRejectedError`. Bad arguments receive status 400 with a message capped at 1,024 characters. A handler failure or result encoding failure receives status 500 with a fixed message. The module logs the underlying cause. Reducers reject invalid caller arguments with a sender error. Scheduled procedures return unit.

Pass `onDefect` to `build(module, impls, { onDefect })`. Remove the trailing observer argument from `provideConstrainedServerSupport` and `provideConstrainedServerRuntime`. An observer receives the cause once for each undeclared failure, including unexpected host errors and async work inside a synchronous handler. Zero-length sleeps complete synchronously. A positive sleep in a synchronous handler dies.

## Additions and defaults

- Choose `required_in_memory`, `required_on_disk` or `no_requirement` through a table's `cachePolicy` or the module's `settings.tableCachePolicyDefault`. The default is in memory. Disk-capable policies require btree indexes. Republish a policy change in place with existing rows and bindings.
- Mount an Effect module with `.mount(key, Library)` and `Builder.mount`, or a native SDK library with `.mountNative<Library>()(key)` and its native implementation. Use `mounts[key].run` for an Effect library and `mounts[key].use` for a native callback. Effect mounts expose nested calls, tables, subscription targets and cache reads. All mounts share the parent database and transaction. An optional `{ name }` pins the wire namespace. The maximum depth is four. Declare environment, HTTP routes, lifecycle hooks and inter-database receivers on the root.
- Array length bounds are optional. `Stdb.array(item)` has no length check. Supply `minimum`, `maximum` or both when needed. When inspecting `Stdb.describe(type).length`, either bound can be absent.
- Table deltas and event inserts retain every change by default. An explicit `bufferSize` bounds memory and signals overflow. Table delta subscribers can also opt into sliding or dropping. Snapshot notifications coalesce because a snapshot reads current rows.
- Table, column, index and callable declarations accept snake_case and preserve authored names at the Effect boundary. Use a plain string schema when your domain has no additional string constraint.
- An undecodable server message invalidates the affected WebSocket cache and parks a supervisor by default. A normal connection loss preserves the last rows for the same identity. A changed identity or failed token refresh revokes them. Keep a token across reconnects when the client should retain its identity.
- `IdcPump.drain({ deliveriesMax })` defaults to 1,000 deliveries. A refused connection stops the pump, and exhausting the bound with pending rows raises `RangeError`.
